# NOVARIS B2B Website — Image-Matched Version

This package was rebuilt from scratch using the supplied reference image as the visual direction.

## Deploy to GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository.
3. Upload **all files and folders inside this package** to the repository root.
4. Open **Settings → Pages**.
5. Set **Source: Deploy from a branch**.
6. Choose **main / root** and save.
7. Wait 1–3 minutes for the GitHub Pages URL.

## Before production launch
- Replace `sales@novaris.example` in `assets/script.js` and the contact section.
- Replace the placeholder phone number.
- Replace the certification marks and factory statistics with verified company information.
- Replace case-study claims with real or clearly labeled portfolio examples.
- Connect Formspree, HubSpot, Zoho, Salesforce, or your own API if you want direct RFQ submission.

## Main files
- `index.html` — homepage
- `assets/styles.css` — responsive styling
- `assets/script.js` — mobile menu + RFQ email behavior
- `assets/logo.svg` — editable vector logo
- `assets/images/` — visual assets cropped from the supplied reference image
